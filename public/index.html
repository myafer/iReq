信任根证书

          
        

        

          

            解密 HTTPS 需要客户端信任 iReq 的根证书，只需做一次。证书只在本机生成，私钥不会离开这台机器。
          

          

            手机浏览器如果提示「证书错误」，几乎都是因为地址被跳成了 https。请确认地址栏是
            http://；实在跳不过去，就把本机这个文件隔空投送 / 发邮件到手机安装：
            data/ca/reqlite-ca.pem
          

          

            下载 .cer（推荐）
            下载 .pem
          

          
手机直接装（推荐路径）

          
    
            
  1. Wi-Fi 代理指向 —（HTTP / HTTPS 都填这个）
    2. 
            
  2. 浏览器打开 — —— 这个页面会给出下载按钮和步骤
    3. 
            
  3. 下载后：iOS 去 设置 › 已下载描述文件 › 安装
    4. 
            
  4. iOS 还要多一步：设置 › 通用 › 关于本机 › 证书信任设置，打开 iReq Root CA
    5. 
          

          

            没配代理也能打开这个地址；配了代理也能打开（代理端口自己会应答，不会绕圈）。
          

          
macOS（抓本机 HTTPS 必做）

          

            手机装的是描述文件，本机要单独信任根证书，否则 Safari / Chrome 会报证书错误。
            双击 .pem 导入钥匙串只算「安装」，还得把「使用此证书时」改成「始终信任」；
            直接复制下面第一条（免 sudo）会一次完成安装 + 信任。别的抓包工具的 CA 不能替代。
          

          
—

          
Android

          
    
            
  1. 打开上面的地址下载 .cer，通知栏点开或 设置 › 安全 › 加密与凭据 › 安装证书 › CA 证书
    2. 
            
  2. Android 7+ 应用默认只信系统证书，抓自家 App 建议用 debug 包并配 networkSecurityConfig
    3. 
          

          
Windows / Linux

          
certutil -addstore -user Root reqlite-ca.pem   # Windows
sudo cp reqlite-ca.pem /usr/local/share/ca-certificates/ && sudo update-ca-certificates   # Debian 系

        

        

          个别 App 有证书固定（pinning），请把它加进「设置 › 跳过解密的域名」
