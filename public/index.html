常见系统服务 按需添加，别把要抓的域名也一并透传

          

          

            为什么这些域名会 TLS 握手失败？
            
    
              
  • 客户端不信任 iReq 根证书：系统服务常自带证书校验 / 证书固定，装了根证书也不认。
    • 
              
  • 客户端只接受 HTTP/2：解密通道只提供 HTTP/1.1，ALPN 协商不上会直接断开。
    • 
              
  • 端口跑的不是 HTTP：私有二进制协议被当成 HTTP 解析，握手后没有请求也会记失败。
    • 
              
  • 加入本列表后走裸隧道，能连上但看不到明文；想看明文只能让客户端信任根证书。
